### 4.2 路由清单

| 方法 | 路径 | 类型 | 说明 |
|---|---|---|---|
| GET | `/register` · `/login` | 页面 | 注册 / 登录表单 |
| POST | `/register` · `/login` · `/logout` | 页面 | 提交（含 CSRF） |
| GET | `/team` · `/team/join` | 页面 | 队伍工作台 / 建队入队 |
| POST | `/team/create` · `/team/join` · `/team/leave` · `/team/reset-code` · `/team/transfer` | 页面 | 组队操作 |
| POST | `/api/auth/register` · `/api/auth/login` · `/api/auth/logout` | JSON | 身份 API |
| GET | `/api/me` | JSON | 当前用户 + 队伍 + 配额 |
| POST | `/api/team` · `/api/team/join` · `/api/team/leave` | JSON | 组队 API |

### 4.3 决策落地

- **D1**：邮箱必填唯一、作为登录账号；学号可选。
- **D5**：入队/退队以邀请码为索引；成员可退队、队长退队需先转让。
- **D6**：CSRF 用 **Flask-WTF `CSRFProtect`**（全局校验，`/api/submit` 暂豁免）。
- **D7**：登录限频（内存计数，5 次锁 15 分钟）。
- **D8**：`role` 仅 `player`/`admin`。
- **D9**：`/api/submit` 登录态优先、回退表单 `team`。
- **D10**：方案 B——运行时 SQLite，demo 数据 CSV 启动导入。
