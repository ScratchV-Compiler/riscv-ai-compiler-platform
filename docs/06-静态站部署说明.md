# 静态演示站（GitHub Pages）部署说明

## 结论：Pages 必须用「GitHub Actions」作为 Source

本平台的仓库是 Flask 动态应用，GitHub Pages 只能托管静态文件，因此走
`tools/export_static.py` 把只读页面导出成静态站，再由 `.github/workflows/pages.yml` 发布。

**关键前提**：仓库 **Settings → Pages → Build and deployment → Source 必须选 `GitHub Actions`**。

若 Source 仍为 `Deploy from a branch`，会出现两种错误现象：

| 现象 | 原因 |
|---|---|
| 打开 `/riscv-ai-compiler-platform/` 看到的是 **README**（Jekyll 渲染） | Pages 在构建**分支根目录**，而根目录只有源码，没有 `index.html` |
| `deploy` 任务报错 `Pages site not configured for GitHub Actions` | `actions/deploy-pages` 要求 Source 为 Actions |

## 发布流程

```
push 到 main
   → build 任务：装依赖 → python tools/export_static.py → 上传 dist/ 产物
   → deploy 任务：把产物发布到 github-pages 环境
```

站点地址：`https://<owner>.github.io/<repo>/`

## 本地预览

```bash
python tools/export_static.py
python -m http.server 8899 --directory dist     # 然后开 http://localhost:8899
```

## 已知约束

- 只导出**只读页面**；提交评测、注册登录、建队入队需要后端，静态站上会跳到 `demo-notice.html`。
- 榜单数据来自 `data/demo_submissions.csv`（导出时由 `seed.py` 确定性重建，CI 里也能复现）。
- 依赖钉 `Werkzeug==2.3.7`：3.x 移除了 `__version__`，Flask 2.3.2 的 test client 会抛 `AttributeError`。
