配套编译器：ScratchV

GitHub 仓库 ↗

ScratchV 是本次赛题配套的开源 AI 编译器——「从 ONNX 到 RISC-V 机器码， 一个你完全看得懂的 AI 编译器」。本题考的是让编译器产出更省的 RV32IM 代码： 拿它当起点，读懂它、改它、把它优化得更快，就是最直接的通关路径。 强烈建议从这里开始，别把自己困在逐条指令的调参里。

平台对汇编的来历没有任何限制——ScratchV 生成的、你改造 ScratchV 后生成的、 或任何其他工具生成的，都按同一把尺子计分。先把基线跑出来，再谈优化。 

git clone https://github.com/ScratchV-Compiler/ScratchV.git
cd ScratchV && pip install -e .    # 装完即可编译赛题模型到 RV32IM
打开 GitHub 仓库 在线课程（浏览器里学）
